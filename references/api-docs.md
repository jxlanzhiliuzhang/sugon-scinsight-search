# searchAcademicLiterature MCP 接口参考

## 服务配置

- MCP 服务：`https://sci.ksai.scnet.cn:58043/scnetmcp`
- 传输方式：Streamable HTTP
- 请求超时：360000 毫秒
- 核心工具：`searchAcademicLiterature`

认证方式和认证配置不属于本 Skill 的配置内容，不在此文件中声明或保存。

## 工具用途

根据用户提供的自然语言问题或关键词，检索运行时已配置并启用的学术数据源，并聚合返回结构化文献结果。

默认数据源包括：

- Crossref：DOI、出版物、作者和年份等元数据
- Semantic Scholar：论文、作者、引用和相关性
- OpenAlex：文献、作者、机构、期刊和引用
- arXiv：AI、计算机科学、物理、数学等领域的预印本

以上是底层聚合来源，不是本 Connector 额外暴露的独立工具。

## 参数

| 参数 | 类型 | 必填 | 限制 |
|---|---|:---:|---|
| `query` | string | 是 | 用户原始问题或关键词，最长 128 个字符 |
| `topN` | integer | 否 | 最大 50；调用方未收到数量要求时推荐传 10 |

### 调用示例

```text
searchAcademicLiterature(
    query="帮我找近五年大模型在科学发现中的应用论文",
    topN=10
)
```

调用方必须原样传递用户的 `query`，不得翻译、改写、截断、摘要、拆解或替换为 Boolean Query。用户指定的时间条件和数量条件也必须保留在原始 `query` 中。

如果 `query` 超过 128 个字符，不得自行截断或生成替代 query，应告知用户当前限制。用户要求超过 50 篇时，`topN` 最大只能传 50，并明确说明单次上限。

## 返回字段

每条文献结果通常包含：

```json
{
  "title": "论文标题",
  "authors": ["作者"],
  "year": 2025,
  "doi": "10.example/example",
  "abstract": "摘要",
  "citationCount": 0,
  "source": "OpenAlex",
  "url": "https://example.org/paper"
}
```

不同数据源的字段可能不完整。空字段必须如实展示，不得猜测。`doi` 和 `url` 是独立字段；结果展示时必须逐条包含 `url`，为空时写“链接：无”。

## 错误处理

必须区分：

- 参数错误：检查 `query` 原始内容、长度和 `topN` 范围。
- 401/403：认证或访问权限错误；保留实际错误含义。
- 429：请求过于频繁，稍后重试。
- 500/503：服务端异常或暂时不可用。
- 超时/网络错误：说明请求未完成，不能说成没有结果。
- JSON-RPC 错误：保留错误代码和消息，不伪造成功结果。
- 成功但 `results=[]`：说明本次检索未返回相关文献，不等同于该领域没有论文。

工具失败时不得使用其他来源结果冒充本 Connector 的结果，也不得补造论文信息。

## 输出要求

输出开头必须包含：

```text
📚 检索来源:科学文献洞察智能体-文献检索
```

纯检索请求只展示实际结果，不自动添加论文评价、趋势或研究空白分析。生成文档时，也必须在开头或页眉保留来源声明。
